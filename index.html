NEXXUS Sandbox

A local-first workspace built from independent, signed engines that talk through one bridge. Runs on your machine, stays on your machine, and only touches the folders you hand it.

Quick start

  1. Start the stack. Run START_NEXXUS.bat (or start_all_engines.bat). Engines bind to loopback only by default.
  2. Serve this page. Run python site_server.py, then open http://127.0.0.1:8787.
  3. Install it. Press Install app above. The service worker caches the shell so the page opens offline.
  4. Grant folders. Open Operator mode and add each folder you want NEXXUS to work in. Nothing else is reachable.
  5. Check health. Each engine answers health and ping; a failing engine is reported without stopping the others.

Operator mode (v1 scope)

In v1, operator mode works only inside folders you explicitly grant. Anything outside a granted folder is refused, not prompted for.
  • Access is an allow-list of folders, empty by default. Granting is a deliberate user action; revoking takes effect immediately.
  • Paths are resolved to their real location before the check, so .. segments and symlinks cannot escape a granted folder.
  • Every operator action, allowed or refused, is written to the logs.
  • Granting a folder does not grant its parents or siblings.

Mesh contract

Every engine answers four calls:

healthIs the engine alive and consistent?
pingCheap liveness check.
messageDeliver a message to the engine's inbox.
instructAsk the engine to perform work.

Security model

  • Loopback-only by default; secrets redacted in logs.
  • Failed signatures are refused, logged and quarantined; quarantined copies are inert.
  • Admin token required for overrides.
  • This site's server serves a fixed whitelist of files and caps all submitted text.
